# أمواج Resort - Booking Website

A modern, responsive resort booking website built with Next.js 14, TypeScript, and Tailwind CSS.

## Features

- 🏖️ Beautiful hero slider showcasing resort amenities
- 🏠 Two luxury resort options with detailed information
- 📅 Integrated booking system with date selection
- 📱 Fully responsive design (1920x1020 optimized)
- 🎨 Modern UI with Tailwind CSS
- 🔍 Image galleries for each resort
- 📜 Booking policies and terms

## Getting Started

### Install dependencies:
```bash
pnpm install
```

### Run the development server:
```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to view the website.

## Project Structure

- `/src/app` - Next.js App Router pages
- `/src/components` - React components
- `/src/data` - Resort data and content
- `/src/types` - TypeScript type definitions
- `/assets` - Images and media files

## Technologies

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Embla Carousel
- Lucide Icons
- date-fns
